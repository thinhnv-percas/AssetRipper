AssetRipper (Python port)

This is a Python/Flask port of AssetRipper.GUI.Web. "Load File" browses a single raw SerializedFile/bundle's metadata. "Load Folder" runs the full game-structure pipeline (platform discovery, dependency resolution, the standard asset processors) and is what Export needs. See python/ROADMAP.md for what's ported and what's still a documented gap (settings pages, several asset preview tabs, and assets whose payload lives in an external .resS file).

Load a file

Quick metadata browsing of one raw file -- can't be exported (no game/platform structure).

Load a folder

Loads an entire game directory and runs the standard processors -- required before Export.
